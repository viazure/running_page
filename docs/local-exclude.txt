# Local-only git excludes for this project.
#
# WHY A TEMPLATE INSTEAD OF .gitignore
# .gitignore is kept identical to upstream on purpose. The upstream workflow
# commits raw device exports and generated splits with `git add .` when
# SAVE_DATA_IN_GITHUB_CACHE is false (run_data_sync.yml: "commit FIT/GPX/TCX/
# splits via git add (do not gitignore them)"), so a repo-wide rule would
# silently stop every user who keeps data in git from ever committing a run.
#
# If this machine keeps data in the Actions cache instead, those folders hold
# private GPS and health data that should never be pushed, and the generated
# public/ artifacts are redundant. Copy this list into the clone's own exclude
# file, which git never commits:
#
#     pnpm run setup:exclude
#
# That writes everything below into .git/info/exclude between marker lines, so
# it can be re-run after a pull to pick up changes.
#
# Do NOT `git config core.excludesFile` to this file: that setting is global and
# would leak these rules into every other repository on the machine.
